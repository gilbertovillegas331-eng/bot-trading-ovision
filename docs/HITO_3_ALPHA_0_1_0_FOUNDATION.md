# Hito 3 — Alpha 0.1.0 Foundation

**Estado:** Activo

## Objetivo

Conseguir el primer arranque verificable de OVISION y establecer la base de integración con MetaTrader 5.

## Entregables incluidos

- Repositorio profesional.
- OVI CORE.
- Configuración JSON.
- Logger.
- Servicio MT5 inicial.
- Modelo MarketData.
- Vision Engine inicial.
- Detectores estructurales iniciales.
- Pruebas unitarias básicas.

## Criterio de cierre

OVISION inicia, carga la configuración, crea logs, se conecta a MT5, obtiene una vela cerrada válida y supera sus pruebas básicas.
