# Market Context & MTF Engine v1

## Contexto

Combina:
- structure;
- liquidity;
- volatility;
- sessions;
- instrument profile;
- data quality.

Contexto no equivale a señal.

## Roles MTF

MACRO, BIAS, SETUP, EXECUTION, TRIGGER.

No hardcodear H4/H1/M15/M5 como única verdad.

## Conflict

El desacuerdo entre timeframes se representa explícitamente.

## Volatility

UNKNOWN, COMPRESSED, NORMAL, EXPANDED, EXTREME.

## MarketRegime

UNKNOWN, TRENDING, RANGING, TRANSITIONAL, VOLATILE_EXPANSION, LOW_VOL.

## Scoring

ContextScore = coherencia/calidad, no win probability.
Confidence es distinto del score.
