# Historia consolidada del proyecto

## Origen

OVISION nació como una idea de análisis técnico y evolucionó hacia una plataforma modular de inteligencia para mercados.

## Evolución principal

1. Filosofía: comprender antes que predecir.
2. Enciclopedia técnica: BOS, CHOCH, MSS, Liquidez, OB, FVG y conceptos relacionados.
3. OVI MIND: observación, memoria, comprensión, razonamiento, crítica, decisión y explicación.
4. Sistema universal de eventos y ciclos de vida.
5. Modelo universal de objetos y grafo de conocimiento.
6. Arquitectura independiente de MetaTrader 5.
7. Python como núcleo y MQL5/MT5 como integración inicial.
8. Desarrollo por Hitos, Sprints, versiones y repositorio GitHub.
