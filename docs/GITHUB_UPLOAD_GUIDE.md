# Guía para subir OVISION a GitHub

1. Abra el repositorio privado `OVISION`.
2. Seleccione **Add file**.
3. Seleccione **Upload files**.
4. Descomprima el ZIP de OVISION en su computador.
5. Arrastre el contenido de la carpeta descomprimida, no el ZIP.
6. Escriba el mensaje: `Initial commit: OVISION Alpha 0.1.0 Foundation`.
7. Confirme el commit directamente en la rama `main`.
8. Verifique que aparezcan README, app, core, config, docs, engines, models, services y tests.

No suba contraseñas, números de cuenta ni archivos `.env`.
