# ADR-096 — Forex primero para validación, no como límite arquitectónico

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Forex primero para validación, no como límite arquitectónico se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener una evolución gobernada, incremental y sostenible del producto.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
