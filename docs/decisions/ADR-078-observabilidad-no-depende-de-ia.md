# ADR-078 — Observabilidad no depende de IA

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Observabilidad no depende de IA se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Hacer la plataforma operable, segura y observable antes de producción.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
