# ADR-091 — APIs separadas por privilegio

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

APIs separadas por privilegio se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Evitar ambigüedad de producto y proteger la claridad y seguridad del usuario.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
