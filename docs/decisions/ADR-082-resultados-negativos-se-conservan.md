# ADR-082 — Resultados negativos se conservan

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Resultados negativos se conservan se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Reducir sesgos de investigación, regresiones y sobreajuste antes de promover lógica.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
