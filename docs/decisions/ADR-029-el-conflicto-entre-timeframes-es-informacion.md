# ADR-029 — El conflicto entre timeframes es información

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

El conflicto entre timeframes es información se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener interpretación de mercado consistente, explícita y auditable sin introducir semántica ambigua.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
