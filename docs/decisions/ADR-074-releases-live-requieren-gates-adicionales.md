# ADR-074 — Releases live requieren gates adicionales

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Releases live requieren gates adicionales se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Hacer la plataforma operable, segura y observable antes de producción.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
