# ADR-017 — Protected levels con lifecycle explícito

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Protected levels con lifecycle explícito se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener interpretación de mercado consistente, explícita y auditable sin introducir semántica ambigua.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
