# ADR-016 — Separar pivote y clasificación estructural

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Separar pivote y clasificación estructural se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener interpretación de mercado consistente, explícita y auditable sin introducir semántica ambigua.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
