# ADR-036 — NO_TRADE es una salida de primera clase

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

NO_TRADE es una salida de primera clase se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Separar decisión analítica, riesgo y ejecución para reducir errores operativos y proteger capital.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
