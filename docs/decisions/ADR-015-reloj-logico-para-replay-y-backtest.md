# ADR-015 — Reloj lógico para replay y backtest

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Reloj lógico para replay y backtest se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Preservar contratos de datos coherentes, reproducibles y neutrales al proveedor.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
