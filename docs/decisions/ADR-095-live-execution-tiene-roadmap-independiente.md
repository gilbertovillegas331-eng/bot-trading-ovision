# ADR-095 — Live execution tiene roadmap independiente

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Live execution tiene roadmap independiente se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener una evolución gobernada, incremental y sostenible del producto.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
