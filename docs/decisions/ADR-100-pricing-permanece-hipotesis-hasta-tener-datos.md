# ADR-100 — Pricing permanece hipótesis hasta tener datos

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Pricing permanece hipótesis hasta tener datos se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener una evolución gobernada, incremental y sostenible del producto.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
