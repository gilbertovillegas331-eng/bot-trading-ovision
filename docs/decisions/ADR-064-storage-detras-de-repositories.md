# ADR-064 — Storage detrás de repositories

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Storage detrás de repositories se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Garantizar trazabilidad, recuperación, migración y reproducibilidad histórica.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
