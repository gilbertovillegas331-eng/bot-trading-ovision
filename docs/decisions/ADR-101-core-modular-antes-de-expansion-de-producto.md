# ADR-101 — Core modular antes de expansión de producto

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Core modular antes de expansión de producto se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener una evolución gobernada, incremental y sostenible del producto.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
