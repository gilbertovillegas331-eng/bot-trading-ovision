# ADR-033 — No double counting de evidencia correlacionada

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

No double counting de evidencia correlacionada se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener interpretación de mercado consistente, explícita y auditable sin introducir semántica ambigua.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
