# ADR-010 — Semántica explícita del volumen

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Semántica explícita del volumen se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Preservar contratos de datos coherentes, reproducibles y neutrales al proveedor.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
