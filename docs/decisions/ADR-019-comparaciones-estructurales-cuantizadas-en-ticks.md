# ADR-019 — Comparaciones estructurales cuantizadas en ticks

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Comparaciones estructurales cuantizadas en ticks se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener interpretación de mercado consistente, explícita y auditable sin introducir semántica ambigua.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
