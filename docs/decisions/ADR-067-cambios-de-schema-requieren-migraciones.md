# ADR-067 — Cambios de schema requieren migraciones

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Cambios de schema requieren migraciones se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Garantizar trazabilidad, recuperación, migración y reproducibilidad histórica.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
