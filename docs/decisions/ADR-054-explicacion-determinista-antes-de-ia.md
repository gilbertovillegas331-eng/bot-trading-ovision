# ADR-054 — Explicación determinista antes de IA

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Explicación determinista antes de IA se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener la IA subordinada a evidencia determinista y evitar hechos o números inventados.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
