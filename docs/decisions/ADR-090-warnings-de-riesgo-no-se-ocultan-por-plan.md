# ADR-090 — Warnings de riesgo no se ocultan por plan

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Warnings de riesgo no se ocultan por plan se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Evitar ambigüedad de producto y proteger la claridad y seguridad del usuario.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
