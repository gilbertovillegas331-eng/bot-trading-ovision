# ADR-068 — Aislamiento de datos por ambiente

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Aislamiento de datos por ambiente se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Garantizar trazabilidad, recuperación, migración y reproducibilidad histórica.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
