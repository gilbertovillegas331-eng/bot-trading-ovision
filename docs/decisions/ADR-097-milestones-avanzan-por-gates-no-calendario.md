# ADR-097 — Milestones avanzan por gates, no calendario

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Milestones avanzan por gates, no calendario se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener una evolución gobernada, incremental y sostenible del producto.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
