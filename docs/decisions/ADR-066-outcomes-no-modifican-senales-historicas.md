# ADR-066 — Outcomes no modifican señales históricas

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Outcomes no modifican señales históricas se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Garantizar trazabilidad, recuperación, migración y reproducibilidad histórica.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
