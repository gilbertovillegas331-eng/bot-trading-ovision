# ADR-089 — PAPER y LIVE deben ser inequívocos

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

PAPER y LIVE deben ser inequívocos se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Evitar ambigüedad de producto y proteger la claridad y seguridad del usuario.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
