# ADR-069 — SQLite primero, no como compromiso final

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

SQLite primero, no como compromiso final se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Garantizar trazabilidad, recuperación, migración y reproducibilidad histórica.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
