# ADR-061 — Números críticos se renderizan determinísticamente

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Números críticos se renderizan determinísticamente se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Mantener la IA subordinada a evidencia determinista y evitar hechos o números inventados.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
