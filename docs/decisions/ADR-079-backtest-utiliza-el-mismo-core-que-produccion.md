# ADR-079 — Backtest utiliza el mismo core que producción

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Backtest utiliza el mismo core que producción se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Reducir sesgos de investigación, regresiones y sobreajuste antes de promover lógica.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
