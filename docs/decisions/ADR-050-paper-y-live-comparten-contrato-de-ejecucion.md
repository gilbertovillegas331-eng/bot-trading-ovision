# ADR-050 — Paper y live comparten contrato de ejecución

**Estado:** APPROVED  
**Blueprint:** v1

## Decisión

Paper y live comparten contrato de ejecución se adopta como decisión arquitectónica de OVISION para Blueprint v1.

## Razón

Separar decisión analítica, riesgo y ejecución para reducir errores operativos y proteger capital.

## Consecuencia

La implementación deberá respetar esta decisión o crear un ADR posterior que la superseda explícitamente.
