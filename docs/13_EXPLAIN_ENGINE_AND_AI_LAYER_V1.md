# Explain Engine & AI Layer v1

## Principio

Primero explicación determinista; después IA opcional.

## Flujo

Deterministic Engines -> Evidence Graph -> ExplainEngine -> Structured Explanation -> AI Layer -> Human Narrative

## Evidence types

OBSERVATION, DERIVED_FACT, INFERENCE, SCORE, HYPOTHESIS.

## IA

Puede:
- explicar;
- comparar;
- resumir;
- enseñar.

No puede:
- crear eventos de mercado;
- alterar Risk;
- enviar órdenes;
- modificar producción por sí sola.

## Grounding

Todo output AI debe validarse contra evidencia estructurada. Números críticos se renderizan determinísticamente.
